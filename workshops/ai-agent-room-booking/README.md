# Design an API your AI agent can trust

A ready-to-run, English-language APIOps Cycles mini workshop based on the supplied room booking challenge. Duration: 28 minutes. Groups: 3–4 people with one laptop. Use Value Proposition and Business Impact as the default tracks; Interaction is an advanced option.

- **Distribute before the workshop:** `ai-agent-room-booking-participants.zip` — participant instructions, two completed background canvases and three partially completed starter canvases.
- **Keep for the host:** `facilitator/` — timed run sheet, surprise cards, detailed reference answers and three reference canvases. Release references after the exercise.
- **Archive the complete kit:** `ai-agent-room-booking-complete.zip` — both folders and this README.

Start with [the participant instructions](participants/workshop-instructions.md) and [the facilitator guide](facilitator/facilitator-guide.md).

The JSON files use the installed Canvas Creator 1.9.0 content format and APIOps Cycles method-data 4.2.1 canvas definitions. Business Impact's availability/security/data categories are represented as labelled notes under the current shared risk and mitigation sections. The legacy import/export template in the dependency has older section IDs and is deliberately not used.

Participants use the online Canvas Creator; no installation is needed. Maintainers update these files by importing, editing and exporting JSON in Canvas Creator. From the repository root, run `pwsh -File scripts/build-archives.ps1` to build release ZIPs in `dist/`. Download published ZIPs from [the latest release](https://github.com/APIOpsCycles/apiops-cycles-workshops/releases/latest). Check Canvas Creator on the venue network before running the session.
